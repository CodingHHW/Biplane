                                                                                     Conventional single-view intensity-based 2D/3D registra-
                                                                                  tion algorithms register an acquired 2D image and a 3D
                                                                                  image (e.g., CT scan) by initializing and optimizing the 6D
                                                                                  pose parameters using a cost function such as image intensity
                                                                                  similarity metric. Multi-view 2D/3D registration algorithms
                                                                                  jointly optimize a similarity metric relating to multiple 2D
                                                                                  acquisitions with varying projection geometries. The registra-
                                                                                  tion performance largely depends on the initialization and the
                                                                                  multi-view geometry.
